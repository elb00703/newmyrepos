Сайт "BookClub" — Книжный клуб для начинающих
Сайт, где участники книжного клуба обсуждают прочитанные книги и делятся впечатлениями.

Возможности сайта:

1. Главная страница
- Приветствие и описание клуба
- Список текущих книг для чтения
- Календарь встреч (дата/время)

2. Страница "Книги"
- Карточки книг с названием, автором, обложкой
- Краткое описание сюжета
- Кнопка "Обсудить" (ведёт на форму комментария)

3. Страница "Отзывы"
- Форма добавления отзыва:
  - Поле "Ваше имя"
  - Поле "Выберите книгу" (выпадающий список)
  - Текстовое поле "Ваше впечатление"
  - Кнопка "Отправить"
